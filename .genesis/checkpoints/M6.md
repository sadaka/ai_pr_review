## Micro-plan · 2026-09-07

**User design decisions (2026-09-07) — all "recommended" option:**
1. **e2e = direct-drive.** The demo test instantiates the 4 real M4 `SpecialistAgent` subclasses + calls `orchestrator.nodes.aggregate()` directly (M5-style). `graph.py` rewiring stays deferred.
2. **Freeze boundary widened** to also permit `agents/base_agent.py`, `agents/llm_client.py`, `orchestrator/nodes.py` — the cross-cutting `emit_agent_event` + BudgetGuard hooks. Legal: `observability/**` is the documented exception to `dependency_direction`. Logged in the deviations table.
3. **BudgetGuard reads raw `agent_events`**: `SUM(cost_usd) WHERE ts >= date_trunc('day', now())`; raises `BudgetExceeded` when `spend >= daily_cap`, checked at the top of every agent run *before* any span/LLM call. `agent_health_1m` stays the dashboard's read path (documented, not used by the guard — refresh lag).
4. **Cap**: `DAILY_BUDGET_USD` env var, overridable via `BudgetGuard(daily_cap_usd=...)` for tests. `economics/pricing.py` holds an approximate OpenAI per-1M-token price map keyed by model + a "verify against live pricing" note.

**Dependency-direction guard (same trick M5 used):** `agents/base_agent.py` imports `observability` (exempt) but NOT `economics` — it names a local `SupportsBudgetCheck` Protocol and the real `BudgetGuard` is injected. `observability/events.py` imports `economics.pricing` (one pure helper module; observability is cross-cutting) to stamp `cost_usd` from `(model, tokens_in, tokens_out)`.

**Files (widened freeze boundary):**
- `observability/__init__.py`
- `observability/events.py` — `AgentEventSink(pool)`: `emit(*, review_id, agent, event_type, span_id=None, parent_span=None, model=None, tokens_in=None, tokens_out=None, cost_usd=None, latency_ms=None, outcome=None, confidence=None, payload=None)` → one `INSERT INTO agent_events VALUES (now(), ...)`. When `cost_usd is None` and `model`+tokens present, computes it via `economics.pricing.cost_usd`. `NullEventSink` (no-op) so agents run without observability configured. `SupportsEmit` Protocol. `create_pool(url)` (command_timeout=10). `@asynccontextmanager span(sink, *, review_id, agent, name, parent_span=None)` → emits `span.start` then `span.end` with `latency_ms`, yields the generated `span_id`.
- `observability/tracing.py` — `get_trace(pool, review_id) -> list[dict]` = `SELECT ... WHERE review_id=$1 ORDER BY ts`; `trace_summary(rows)` → `{agents:set, event_types:set, total_cost_usd, llm_calls}`.
- `economics/__init__.py`
- `economics/pricing.py` — `PRICE_PER_1M: dict[str, tuple[float,float]]` (`gpt-5.4-mini` + `_DEFAULT`), `cost_usd(model, tokens_in, tokens_out) -> float`. Comment: approximate, verify.
- `economics/cost_repository.py` — `CostRepository(pool)`: `spend_today_usd() -> float` (raw `agent_events` sum, UTC day), `spend_for_review(review_id) -> float`. `SupportsSpendToday` Protocol.
- `economics/budget.py` — `BudgetExceeded(RuntimeError)`; `BudgetGuard(cost_repo, *, daily_cap_usd)`: `check(*, agent) -> None` raises when `spend_today >= cap`. `from_env(cost_repo, *, cap=None)` reads `DAILY_BUDGET_USD`.

- `orchestrator/nodes.py` — `aggregate()` gains `events: SupportsEmit | None = None`; after `decide()`, emits one `decision` event (`agent="aggregator"`, `outcome=decision.value`, `confidence=score`, `payload={findings, threshold}`). ## Q+A block · 2026-09-07

**Q1 (design decision):** Why does `review_id` default to `None`, and why is the budget
guard injected as a `SupportsBudgetCheck` Protocol rather than imported?
- Human: "made just to save budget from going beyond limit; keeps response to a baseline
  instead of failure."
- Verdict: PARTIAL — that's the *budget* rationale, not the two asked. Corrected:
  `review_id=None` makes observability opt-in so the M4 path (and its 5 tests, and
  Tiger-less unit runs) is preserved byte-for-byte; the Protocol injection keeps
  `agents/` from importing `economics/**`, protecting `dependency_direction`. Human
  acknowledged the correction.

**Q2 (edge case):** cap `$0.01`, today's spend `$1.00`, 4-agent fan-out — what happens?
- Human (first): "if budget overshoots the LLM call will not fire and a log entry will
  be made."
- Verdict: PARTIALLY WRONG on the log entry — corrected: all 4 agents independently
  raise `BudgetExceeded` (each `check()` sees `$1.00 >= $0.01`), no LLM call fires, and
  **nothing lands in `agent_events`** because `check()` raises before the first
  `span.start` emit. No "blocked" row exists in M6. Human confirmed understanding ("yes").

**Q3 (change impact):** Why sum raw `agent_events` instead of reading `agent_health_1m`?
- Human: "getting cost used from the database directly makes it more reliable."
- Verdict: CORRECT direction. Full reason: the continuous aggregate lags its refresh
  policy (~1 min) so it can't see same-run costs; raw `SUM` is fresh. Trade-off: a row
  scan vs a precomputed rollup — fine now, needs a short-window rollup/cache at high
  throughput. `agent_health_1m` stays the dashboard read path.
